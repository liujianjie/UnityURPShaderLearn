# 我对 Shader 的理解

## Chapter 9：我是怎么理解灯光坐标系的

1. **先定光线往哪儿走。** 例子里的光线在世界 XY 平面内，方向是 `(3, -4, 0)`。我把它除以长度 5，得到单位方向 `F = (0.6, -0.8, 0)`。
2. **把光线反过来，就是后轴。** `K = -F = (-0.6, 0.8, 0)`。这个三元组是用世界轴写的。换成灯光自己的坐标，K 就是灯光的 `+Z`，顺着光照出去则是灯光的 `-Z`。
3. **再选哪边是「上」。** 光线在世界 XY 平面内，所以世界 `+Z` 和 `-Z` 都和它垂直。我可以选 `U = (0, 0, 1)`；配套演示选的是 `(0, 0, -1)`。这是在选画面哪边朝上，两种选法都成立。
4. **用上轴和后轴算右轴。** 按右手系，`R = U × K`。这样三根轴就定了，我知道灯光坐标系**朝哪儿**。要写完整的视图矩阵 `V_light`，还要知道从**哪里**开始量，也就是原点 `O`。

### 我卡住的是世界到灯光的矩阵怎么组装

我当时想弄懂的是 `V_light` 本身怎么组成。找到 `R、U、K` 之后，先用「灯光原点 `O` 换过去是 `(0, 0, 0, 1)`」这个条件确定第四列，然后就能组装矩阵。对我最有帮助的一步是**最后一列的前三个数，是为了把灯光原点 `O` 的三个读数清零**。第一行已经沿 R 读到了 `3.48`，要清零就补 `−3.48`。

矩阵做好以后，我再引入待转换的 A。`R · A − R · O` 是先在同一刻度上读 A 和 O，再用差值读出 A 的灯光横坐标。[只用 O 推出第四列的算式](Chapter09-Shadow-QA.md#view-first-row)
