# Shader 学习笔记

这里记录学习 Unity URP Shader 过程中提出的问题、推导过程和最终结论。

## 组织方式

- 按书本章节或功能章节分文件，而不是“一问一文件”。
- 同一章节的后续问题继续追加到对应文件。
- 只有跨越多个章节、内容足够独立时，才新建专题文件。
- 图示尽量与相关 Shader 放在同一目录，并从笔记中链接过去。
