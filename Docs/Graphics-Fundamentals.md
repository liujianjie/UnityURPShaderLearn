# 计算机图形学基础

这里记录换一套引擎仍成立的图形学和数学原理。Unity 的具体变量与写法见 [Unity 与 Shader 实践](Unity-Shader-Practice.md)。

<a id="view-space-basis"></a>
## 灯光朝向已经确定，为什么还要选上轴和原点？

一个朝向只确定视线轴。相机绕这根轴旋转时，仍在看同一个方向，画面的「上」却会变。以右手视图、朝前为局部 `−Z` 的约定为例：先用单位前向 `F` 定出后轴 `K = −F`；从参考上方向中去掉平行于 `K` 的分量并归一化，得到上轴 `U`；再用 `R = U × K` 得到右轴。参考上方向不能与 `K` 平行。

三根轴只决定朝向。给出原点 `O` 之后，才能说从哪里出发、沿每根轴走多少到达点 `P`。同一根轴也可以用不同坐标系描述，例如局部后轴在局部坐标里是 `(0, 0, 1)`，它在世界坐标里的分量由朝向决定。

<a id="view-space-coordinates"></a>
### 为什么与三根轴点积就能得到新坐标？

`(xₗ, yₗ, zₗ)` 的定义是从 `O` 出发，沿 `R`、`U`、`K` 分别走这三个带符号的距离，最后到达 `P`。把 `O` 移到左边，得到已知的世界位移，右边的三个待求系数给出同一段位移在灯光轴上的分量。

$$
P - O = x_\ell R + y_\ell U + z_\ell K
$$

三根轴都长 1 且两两垂直。等式两边与 `R` 点积，因为 `R · R = 1`，`U · R = K · R = 0`，右边只剩 `xₗ`。对 `U`、`K` 分别做同样的计算，就能取出 `yₗ` 和 `zₗ`。

$$
\begin{bmatrix}x_\ell\\y_\ell\\z_\ell\end{bmatrix}
=\begin{bmatrix}
R\cdot(P-O)\\
U\cdot(P-O)\\
K\cdot(P-O)
\end{bmatrix}
$$

把求出的三个系数代回 $O + x_\ell R + y_\ell U + z_\ell K$，就能验算是否还原原来的世界点。

<a id="view-matrix-construction"></a>
### 为什么视图矩阵把三根轴放在行上？

用列向量时，把视图右轴 `R`、上轴 `U`、后轴 `K` 按列排成 $B=[R\;U\;K]$。第一列乘以局部横坐标，第二、三列分别乘以局部纵坐标和后轴坐标。加上原点 `O`，得到世界位置。这个方向的变换叫**逆视图矩阵**，记为 $V^{-1}$。

下面的 $p_{\mathrm{world}}$ 和 $p_{\mathrm{view}}$ 各表示同一个点的三项坐标。写成矩阵乘法时，都在末尾补 `1`。

$$
\begin{bmatrix}p_{\mathrm{world}}\\1\end{bmatrix}
=
\underbrace{\begin{bmatrix} B & O \\ \mathbf{0}^{\mathsf{T}} & 1\end{bmatrix}}_{V^{-1}}
\begin{bmatrix}p_{\mathrm{view}}\\1\end{bmatrix}
$$

视图矩阵 `V` 从世界坐标换回视图坐标。先减 `O`，再左乘 $B^{-1}$。三根轴都长 1 且两两垂直，所以 $B^{\mathsf{T}}B = I$。这个乘积的对角线是每根轴与自己的点积，其他位置是两根不同轴的点积。因此 $B^{-1}=B^{\mathsf{T}}$。把两步写进一张矩阵会得到

$$
V=\begin{bmatrix}
B^{\mathsf{T}} & -B^{\mathsf{T}}O \\
\mathbf{0}^{\mathsf{T}} & 1
\end{bmatrix}.
$$

左上角的转置把三根轴从列转到行。右上角的第四列前三项是 `−R · O`、`−U · O`、`−K · O`，分别减去原点沿三根轴的读数。

带数值的例子：[第 9 章灯光视图矩阵](Chapter09-Shadow-QA.md#light-matrix-walkthrough)。

<a id="axis-projection-right-angle"></a>
## 为什么垂足到原点的读数由点积给出，屏幕上的角却不一定是直角？

设轴经过 `O`，方向 `R` 长度为 1。先把 `H` 当作轴上任意一点，写成 `H = O + tR`，其中 `t` 是从 `O` 沿轴走的有符号距离。令 `q = A − O`，从 `H` 到 `A` 的位移就是 $q-tR$。

当 `HA` 非零时，点积等于两根向量的长度乘以夹角的余弦。要求直角，就令 `HA` 与 `R` 的点积为零。

$$
0 = \overrightarrow{HA}\cdot R
  = (q-tR)\cdot R
  = q\cdot R-t\underbrace{(R\cdot R)}_{1}
  = q\cdot R-t
$$

解得 `t = q · R`，所以垂足的位置是 `H = O + (q · R)R`。移动 `A` 后重新代入就能求出新的垂足。若 `A` 本来就在轴上，`H = A`，虚线段长度为零。

三维的 `90°` 属于红轴和虚线所在的平面。斜着用正交相机看，这个平面有一个方向会被压短，原本的直角在屏幕上可能变成锐角或钝角。让镜头沿这个平面的法线正对它，就能在屏幕上看到直角。

<a id="homogeneous-clip-space"></a>
## 齐次裁剪空间和屏幕坐标差在哪一步？

顶点先从模型空间变到世界空间，再变到相机的视图空间。乘投影矩阵后得到四分量的齐次裁剪坐标 `(x_c, y_c, z_c, w_c)`。此时还保留 `w_c`：例如左右裁剪边界可以写成 `-w_c ≤ x_c ≤ w_c`，深度边界的约定随图形 API 而异。裁剪之后除以 `w_c`，才得到归一化设备坐标（NDC），再由视口映射到像素。

例如裁剪坐标的 `x_c = 1、w_c = 2`，投影后的 `x_ndc = 0.5`；若 `x_c = 1、w_c = 4`，则 `x_ndc = 0.25`。在覆盖整个视口的纹理上，横向 UV 是 `0.5 × x_ndc + 0.5`，分别为 `0.75` 和 `0.625`。裁剪坐标的 `x_c` 相同，最终落点可以不同。[Direct3D 光栅化与视口](https://learn.microsoft.com/en-us/windows-hardware/drivers/display/rasterizer-block)。

<a id="tangent-frame"></a>
## 法线贴图为什么需要切线、副法线和网格法线？

切线空间是贴在表面上的局部坐标系。做法线映射时，用网格切线 `T` 表示纹理 `+U` 的局部朝向，用副法线 `B` 表示纹理 `+V` 的局部朝向，用网格法线 `N` 表示局部朝外的方向。前两根轴沿表面，第三根轴垂直于它们。曲面各处的基底可以不同；同一个贴图向量因此可以对应不同的世界方向。

若贴图法线解码为 `(nx, ny, nz)`，三项表示沿 `T、B、N` 各走多少。用世界坐标表示这三根轴，就能得到世界方向：`nx*T + ny*B + nz*N`。按列向量乘法写成矩阵时，`T、B、N` 是矩阵的三列。这里变换的是方向，无须加上表面点的世界位置。平坦贴图的 `(0, 0, 1)` 得到的就是 `N`；例如 `(0.6, 0, 0.8)` 表示在保留朝外分量的同时往 `T` 倾斜。

<a id="interpolated-normal"></a>
## 顶点法线已经归一化，为什么片元里还要做一次？

**单位向量按分量插值，结果不保证是单位向量。** 例如在两顶点法线 `(1, 0, 0)` 和 `(0, 1, 0)` 的等权插值处，结果是 `(0.5, 0.5, 0)`，长度约为 `0.707`。

如果希望 `dot(N, L)` 只表示两方向夹角的余弦，两个输入都要是单位向量。沿用上面的法线，即便光方向与它完全同向，点积也只有约 `0.707`。因此光照计算通常先在片元中把插值后的法线再归一化。顶点法线完全相同时，插值不会改变其长度。

项目里的对照：[第 10 章程序纹理的点积](../Assets/Shaders/Chapter10/Chapter10-ProduceTexture.shader)直接取插值法线；[第 9 章阴影笔记](Chapter09-Shadow-QA.md#33-顶点着色器为什么这样写)记录了在片元中重新归一化的做法。

<a id="fresnel-schlick"></a>
## 什么是菲涅尔效应？为什么用 5 次方和 0.04？

菲涅尔效应描述光到达两种介质的交界面时，反射的比例如何随入射角变化。低头看清澈的水容易看到水底；视线贴着水面看时，更容易看到天空的倒影。球体上也一样：正对相机的位置与轮廓附近的法线朝向不同，因而反射权重不同。

对光滑表面的镜面反射，入射角与反射角相等，所以可以用单位表面法线 `N` 和从表面指向相机的单位向量 `V` 的夹角 `θ` 来算，`dot(N, V) = cos θ`。Schlick 近似把反射率写作：

$$
F(\theta) \approx F_0 + (1 - F_0)(1 - \cos \theta)^5
$$

### 为什么是 5 次方？

`1 - cos θ` 从正对表面时的 `0` 增加到掠射时的 `1`。取 5 次方保留两个端点，但会把中间值压低，例如 `0.5⁵ = 0.03125`。这样，中等角度的反射仍接近基准值，到了接近掠射时才明显上升。[Schlick 原论文 §4.2](https://wiki.jmonkeyengine.org/docs/3.4/tutorials/_attachments/Schlick94.pdf) 用这个容易计算的幂函数来近似完整的菲涅尔曲线。端点加上正入射附近足够平缓的条件并不能唯一确定指数 `5`。

以空气到折射率 `1.5` 的光滑玻璃界面为例，近似式都取 `F₀ = 0.04`；最后一列是非偏振光的完整菲涅尔结果。角度都从法线量起。

| 夹角 | 1 次方 | 4 次方 | 5 次方 | 完整公式 |
| --- | ---: | ---: | ---: | ---: |
| 60° | 52.0% | 10.0% | 7.0% | 8.9% |
| 72° | 70.3% | 25.9% | 19.1% | 19.9% |

### 0.04 怎么从折射率算出来？

`F₀` 是垂直入射时的镜面反射率，也就是入射光能量中被镜面反射回去的比例。对普通非吸收介质，若两侧折射率分别是 `n₁` 和 `n₂`，垂直入射时的菲涅尔公式给出：

$$
F_0 = \left(\frac{n_2 - n_1}{n_2 + n_1}\right)^2
$$

空气约为 `1.0`，以常见玻璃或塑料的 `1.5` 为例：`((1.5 - 1.0) / (1.5 + 1.0))² = (0.5 / 2.5)² = 0.04`，即 **4%**。空气到水用 `1.33` 代入，约为 **2%**，因此 `0.04` 是常用的材质起点，实际值取决于界面两侧的介质。[Filament：折射率与正入射反射率](https://google.github.io/filament/main/filament.html#materialsystem/parameterization/remapping)

项目里的应用见 [第 10 章的 Fresnel 示例](Chapter10-Reflection-Refraction.md#chapter10-fresnel)。
